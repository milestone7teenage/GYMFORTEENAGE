## Как обновляться

### Из v0.5.0 → v1.0.0

1. Экспортируйте текущие данные через Settings → Backup
2. Установите новую версию
3. Импортируйте данные из резервной копии
4. Настройте API ключ для AI Coach (опционально)

> ⚠️ Все локальные данные сохраняются при обновлении
