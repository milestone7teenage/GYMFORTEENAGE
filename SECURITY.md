# Security Policy / Политика безопасности

## 🛡️ Поддерживаемые версии

| Версия | Поддержка |
|--------|-----------|
| 1.0.x  | 🟢 Да     |
| < 1.0  | 🔴 Нет    |

## 📋 Как сообщить о баге

Мы ценим вашу помощь в обеспечении безопасности приложения.

### 🔐 Приватное сообщение

Для уязвимостей, требующих приватности:

1. Откройте Issue с заголовком `[SECURITY] Краткое описание`
2. В описании укажите только необходимые детали
3. Мы свяжемся с вами для уточнения

### 📧 Электронная почта

Для критических уязвимостей: pubgmilestone@gmail.com

**Что указывать:**
- Описание уязвимости
- Шаги для воспроизведения
- Возможные последствия
- Возможные решения (если есть)

**Не указывать:**
- Эксплойты
- Доступ к чужим данным
- Данные реальных пользователей

## ⚠️ Что не следует делать

- Тестировать на продакшене
- Извлекать данные других пользователей
- Нарушать работу приложения
- Публиковать уязвимости без согласования

## 📅 Обработка заявок

| Этап | Срок |
|------|------|
| Подтверждение получения | 48 часов |
| Оценка серьезности | 5 дней |
| Исправление | 1-2 недели |
| Публикация | После исправления |

## 🌟 Рекомендации для разработчиков

### Local Storage
- Все данные хранятся в Application Support
- JSON файлы атомарно перезаписываются
- Нет шифрования (оно требует ключей)

### API Keys
- Не храните ключи в коде
- Используйте Environment Variables
- AI keys хранятся в Keychain (если реализовано)

### UI Security
- Проверяйте валидацию всех вводов
- Блокируйте нежелательные действия
- Предупреждайте об удалении данных
